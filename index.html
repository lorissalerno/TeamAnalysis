Passaggio 1: Seleziona il tipo di dati da importare

Scegli se stai importando un report sulle Efficienza della squadra, sulle vendite (Sales) o sugli Stati (tempi di lavoro, pause, meeting, ecc.).

Sales

Stati

Passaggio 2: Seleziona lo Skill

Scegli a quale Skill associare i dati delle performance da importare.

Con "+ Nuovo" crei uno skill; con "Rinomina" modifichi o elimini quelli esistenti.

Backup Dati

Salva o ripristina i dati del progetto in locale.

Esporta

Backup Completo Tutti i dati, la struttura e i collaboratori.
Backup Struttura Template, grafici e impostazioni, senza dati né collaboratori.
Backup Database Solo i dati performance/vendite e la lista collaboratori.

Importa

Seleziona un file JSON di backup esportato in precedenza: verranno ripristinati solo gli store contenuti nel file.

Anonimizzazione CSV

Anonimizza i nomi dei collaboratori nei file CSV prima di importarli o condividerli. Seleziona più file contemporaneamente: lo stesso collaboratore riceverà lo stesso nome fittizio in tutti i file.

Modifiche non salvate

I dati vivono solo in questo browser — senza backup li perdi

Hai modifiche dall’ultimo backup. Chiudendo ora senza scaricare rischi la perdita definitiva — cache cancellata, altro dispositivo o browser.

Un click su Scarica Backup Completo salva tutto in un file JSON — pronto in 1 secondo.

Il dialogo nativo “Annulla / Esci” di Chrome non è modificabile — questo riquadro è la versione personalizzata con download.
